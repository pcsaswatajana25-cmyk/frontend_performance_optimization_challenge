Frequently Asked Questions

How does ApexPulse capture traces without code modifications? +
ApexPulse utilizes Linux eBPF probes attached directly to kernel network sockets, extracting OpenTelemetry-compliant trace contexts without requiring SDK wrappers.
What is the performance overhead on our production clusters? +
Benchmark testing demonstrates under 0.8% CPU utilization and less than 12MB RAM usage per node agent, making it safe for latency-critical financial services.
Is data encrypted at rest and in transit? +
Yes, all telemetry payloads are encrypted in transit via mTLS 1.3 and at rest with AES-256 encryption. We are SOC2 Type II certified.
